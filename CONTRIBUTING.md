# Contributing

The engine is in a bootstrap phase and its code license has not yet been
approved. External pull requests are not currently accepted.

When contributions open, code submissions will be provided under the code
license recorded by this repository. Knowledge content belongs in a domain
repository and will use a separate content license.

For local changes:

1. run `pnpm install --frozen-lockfile`;
2. keep parsing and validation changes backwards-aware;
3. add or update tests;
4. run `pnpm check`;
5. record unresolved schema or URL choices explicitly.
