# Contributing

By submitting a contribution, you retain your copyright and agree to provide
it under MPL 2.0. No copyright assignment is required. Knowledge content
belongs in a domain repository under CC BY-SA 4.0.

For local changes:

1. run `pnpm install --frozen-lockfile`;
2. keep parsing and validation changes backwards-aware;
3. add or update tests;
4. run `pnpm check`;
5. record unresolved schema or URL choices explicitly.

Do not submit third-party material without verified compatible permission and
complete attribution. AI assistance does not replace those checks.
